# Liquid Glass Parallax

A standalone Three.js liquid-glass parallax animation demo built with Telecladius.

Live demo: https://teleclaudius.bles-software.com/liquid-glass-parallax

## Files

- `index.html` - the complete static front-end animation demo.

## Run Locally

Serve the directory with any static server, then open `index.html` in a modern browser with WebGL support.

```bash
python3 -m http.server 8080
```

## Built With

- Three.js
- html2canvas
- d3-delaunay
- Telecladius
